# Python CLI Task Manager

## Overview

Python CLI Task Manager is a simple command-line application that helps users
manage their daily tasks. It allows users to add, view, edit, delete, search,
and mark tasks as completed. All tasks are stored in a text file, so they remain
available even after the program is closed.

---

## Features

* Add a new task
* View all tasks
* Edit an existing file
